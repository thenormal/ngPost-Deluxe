# Server und Verbindungen

Ein Server ist Ihr Usenet-Anbieter. Sie können mehrere eintragen: Die Posts werden auf alle aktivierten Server hochgeladen.

## Felder

- **Host** und **Port**: von Ihrem Anbieter angegeben. Üblich sind die Ports 563 (oder 443) mit SSL und 119 ohne.
- **SSL**: Verwenden Sie es immer, wenn Ihr Anbieter es anbietet. Es verschlüsselt die Verbindung.
- **Benutzername** und **Passwort**: Ihr Konto.
- **Verbindungen**: wie viele Verbindungen parallel geöffnet werden. Mehr Verbindungen können schneller sein, aber Ihr Anbieter hat ein Limit (oft 20 bis 50). Wird es überschritten, gibt es Fehler.

## Verbindung testen

Klicken Sie vor dem Posten auf **Verbindung testen**. Der Test verbindet sich und meldet sich an und sagt Ihnen, ob Host, Port, SSL-Einstellung oder Zugangsdaten falsch sind.

## Häufige Fehler

- *Verbindung nicht möglich*: falscher Host oder Port, kein Internet, oder eine Firewall oder ein VPN blockiert die Verbindung.
- *Authentifizierung fehlgeschlagen*: falscher Benutzername oder falsches Passwort. Versuchen Sie es nur wenige Male erneut: Anbieter können ein Konto nach vielen fehlgeschlagenen Anmeldungen vorübergehend sperren.
- *Zu viele Verbindungen*: Verringern Sie die Anzahl der Verbindungen.

Siehe auch [Häufige Probleme](12-problems.md).
