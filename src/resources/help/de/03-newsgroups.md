# Newsgroups

Newsgroups sind die Orte im Usenet, an denen Ihre Artikel gepostet werden. Sie werden unter **Einstellungen**, Kategorie **Posts**, Karte **Newsgroups** festgelegt.

## Das Gruppenfeld

Jede Newsgroup ist ein kleiner „Chip“:

- Geben Sie einen Namen ein und drücken Sie **Eingabe**, **Tab**, Komma oder Leerzeichen, um ihn hinzuzufügen.
- Während der Eingabe wird eine kurze Liste gängiger Gruppen vorgeschlagen.
- Klicken Sie auf das **×** eines Chips, oder drücken Sie **Rücktaste** im leeren Feld, um ihn zu entfernen.
- Ein ungültiger Name (zum Beispiel ohne Punkt) wird rot angezeigt.

Ein gültiger Name besteht aus Kleinbuchstaben, Ziffern, `+`, `_` oder `-`, durch Punkte getrennt, zum Beispiel `alt.binaries.test`.

## Prüfungen vor dem Posten

ngPost startet keinen Post, wenn keine Newsgroup vorhanden ist oder eine davon ungültig ist. Die Meldung fordert Sie auf, sie in den Einstellungen zu korrigieren.

## Wohin die Posts gehen

Wenn Sie mehrere Gruppen haben, legt das Menü neben dem Feld fest, wohin jeder Artikel geht:

- **Alle Gruppen in jedem Post** (Standard): Jeder Artikel wird in alle Gruppen gepostet.
- **Eine zufällige Gruppe für jeden Post**: Jeder Post geht in eine zufällig gewählte Gruppe der Liste.
- **Eine zufällige Gruppe für jede Datei**: Jede Datei geht in eine zufällige Gruppe. Dafür ist die Option **Artikel verschleiern** (unter Datenschutz) nötig.

Verwenden Sie zum Lernen eine Testgruppe wie `alt.binaries.test`. Für echte Posts nutzen Sie die Gruppen, die Ihr Anbieter und die Community erwarten.
