# Glossar

**Artikel**: ein kleines Stück einer im Usenet geposteten Datei. Ein Post besteht aus Tausenden von Artikeln.

**Newsgroup**: ein Usenet-Forum, in dem Artikel gepostet werden, zum Beispiel `alt.binaries.test`.

**NZB**: eine Datei mit der Liste der Artikel eines Posts. Sie wird zum Herunterladen benötigt.

**par2**: Wiederherstellungsdateien. Sie erlauben einem Downloader, einen Post zu reparieren, wenn einige Artikel fehlen.

**Redundanz**: der Prozentsatz zusätzlicher par2-Daten. Höher bedeutet sicherer, aber größer.

**Verschleierung**: das Verbergen der Namen in den Betreffzeilen der Artikel. Nur wer die NZB hat, kann den Post finden.

**RAR, 7z**: Archivformate, mit denen die Dateien gepackt werden, mit optionalem Passwort.

**Verbindung**: eine Leitung zum Server. Mehr Verbindungen laden schneller hoch, bis zum Limit Ihres Anbieters.

**SSL**: Verschlüsselung der Verbindung zum Server.

**ETA**: geschätzte Restzeit.

**Warteschlange**: die Liste der Posts, die auf den Upload warten.

**Anbieter**: das Unternehmen, das Ihnen Zugang zu einem Usenet-Server gibt.
