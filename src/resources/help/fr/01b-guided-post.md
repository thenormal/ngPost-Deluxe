# Post guidé

Le Post guidé vous pose quelques questions et prépare le post pour vous. C'est la première entrée de la barre de gauche. C'est une façon de plus de poster : [Post Rapide](04-quick-post.md) et [Post Auto](08-auto-posting.md) restent tels quels et font le vrai travail, avec les mêmes vérifications.

## Quand l'utiliser

Si vous postez pour la première fois, ou ne savez plus quelle page utiliser, commencez ici. Si vous savez déjà ce que vous voulez, vous pouvez quand même l'utiliser pour préparer plusieurs posts et les démarrer ensemble.

## Les cinq étapes

1. **Que voulez-vous faire ?** Poster les fichiers choisis comme **une seule publication**, poster **chaque fichier ou dossier** comme publication distincte, **analyser un dossier une fois**, ou **surveiller un dossier** et poster ce qui arrive.
2. **Quoi poster.** Ajoutez des fichiers et des dossiers (glissez-les dans la fenêtre ou utilisez les boutons ; double-clic sur un élément pour le retirer). Pour une analyse ou une surveillance, choisissez le dossier.
3. **Options.** Choisissez un profil (le profil **Recommandé** est proposé) ou appuyez sur **Personnaliser** pour changer la compression, le nom et le mot de passe aléatoires, par2, le fichier NFO et, pour les choix de Post Auto, ce qui arrive aux fichiers après le post.
4. **Où poster.** Montre vos serveurs (avec le résultat du dernier test), vos newsgroups et le dossier des fichiers NZB. Les boutons ouvrent Serveurs ou Paramètres pour les modifier. Cochez **Ignorer cette étape quand tout est configuré** pour ne la voir que lorsqu'il manque quelque chose.
5. **Résumé.** Montre ce qui sera posté et les vérifications, en mots simples, avec les mêmes solutions que les autres pages. Vous pouvez enregistrer vos choix comme profil avec **Enregistrer ces choix comme profil**. Appuyez sur **Poster** (ou **Commencer la surveillance**).

## Plusieurs posts à la fois

Appuyez sur **Ajouter un autre post** dans le résumé pour en préparer un de plus : ceux déjà préparés sont listés dans **Posts prêts**, où vous pouvez les modifier ou les retirer. Le bouton devient **Tout poster (n)**.

## Bon à savoir

- Une release est préparée comme dans Quick Post, sans toucher à ce que vous y avez préparé ; les autres choix vont dans Auto Posting. Chaque post apparaît ensuite dans la page **Posts**.
- Le programme se souvient de vos derniers choix (pas des fichiers).
- Les éléments déjà dans l'historique sont signalés comme d'habitude avant d'être postés de nouveau.
- Un dossier ne peut être surveillé qu'avec la compression.
