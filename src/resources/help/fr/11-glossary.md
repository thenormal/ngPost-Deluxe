# Glossaire

**Article** : un petit morceau d'un fichier posté sur Usenet. Un envoi est composé de milliers d'articles.

**Newsgroup** : un forum Usenet où les articles sont postés, par exemple `alt.binaries.test`.

**NZB** : un fichier contenant la liste des articles d'un envoi. Nécessaire pour le télécharger.

**par2** : fichiers de récupération. Ils permettent à un téléchargeur de réparer un envoi quand certains articles manquent.

**Redondance** : le pourcentage de données par2 supplémentaires. Plus il est élevé, plus c'est sûr, mais plus c'est volumineux.

**Obfuscation** : masquer les noms dans les sujets des articles. Seules les personnes qui ont le NZB peuvent retrouver l'envoi.

**RAR, 7z** : formats d'archive utilisés pour regrouper les fichiers, avec un mot de passe facultatif.

**Connexion** : un lien avec le serveur. Plus de connexions téléversent plus vite, jusqu'à la limite de votre fournisseur.

**SSL** : chiffrement de la connexion avec le serveur.

**ETA** : temps restant estimé.

**File d'attente** : la liste des envois en attente de téléversement.

**Fournisseur** : l'entreprise qui vous donne accès à un serveur Usenet.
