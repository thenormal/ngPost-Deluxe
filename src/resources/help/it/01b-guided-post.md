# Post guidato

Il Post guidato ti fa alcune domande e prepara il post per te. È la prima voce della barra a sinistra. È un modo in più per postare: [Quick Post](04-quick-post.md) e [Post automatico](08-auto-posting.md) restano come sono e fanno il lavoro vero, con gli stessi controlli.

## Quando usarlo

Se posti per la prima volta, o non ricordi quale pagina usare, parti da qui. Se sai già cosa vuoi, puoi usarlo comunque per preparare più post e avviarli insieme.

## I cinque passaggi

1. **Cosa vuoi fare?** Postare i file scelti come **un'unica release**, postare **ogni file o cartella** come release a sé, **scansionare una cartella una volta**, oppure **monitorare una cartella** e postare ciò che arriva.
2. **Cosa postare.** Aggiungi file e cartelle (trascinali nella finestra o usa i pulsanti; doppio clic su un elemento per rimuoverlo). Per la scansione o il monitoraggio scegli la cartella.
3. **Opzioni.** Scegli un profilo (è suggerito quello **Consigliato**) oppure premi **Personalizza** per cambiare compressione, nome e password casuali, par2, il file NFO e, per le scelte del Post automatico, cosa succede ai file dopo il post.
4. **Dove postare.** Mostra i tuoi server (con il risultato dell'ultimo test), i newsgroup e la cartella dei file NZB. I pulsanti aprono Server o Impostazioni per cambiarli. Spunta **Salta questo passaggio quando tutto è impostato** per vederlo solo quando manca qualcosa.
5. **Riepilogo.** Mostra cosa verrà postato e i controlli, in parole semplici, con gli stessi rimedi delle altre pagine. Puoi salvare le tue scelte come profilo con **Salva queste scelte come profilo**. Premi **Posta** (oppure **Avvia il controllo**).

## Più post insieme

Premi **Aggiungi un altro post** nel riepilogo per prepararne un altro: quelli già pronti sono elencati in **Post pronti**, dove puoi modificarli o rimuoverli. Il pulsante diventa **Posta tutto (n)**.

## Da sapere

- Una singola release viene preparata come in Quick Post, senza toccare quello che hai preparato lì; le altre scelte vanno nel Post automatico. Ogni post compare poi nella pagina **Post**.
- Il programma ricorda le ultime scelte (non i file).
- Gli elementi già presenti nella cronologia vengono segnalati come al solito prima di essere postati di nuovo.
- Una cartella può essere monitorata solo con la compressione.
