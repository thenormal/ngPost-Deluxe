# Server e connessioni

Un server è il tuo provider Usenet. Puoi inserirne diversi: i post vengono caricati su tutti i server abilitati.

## Campi

- **Host** e **Porta**: li fornisce il tuo provider. Le porte più comuni sono 563 (o 443) con SSL e 119 senza.
- **SSL**: usalo sempre quando il provider lo offre. Cifra la connessione.
- **Nome utente** e **Password**: il tuo account.
- **Connessioni**: quante connessioni vengono aperte in parallelo. Più connessioni possono essere più veloci, ma il provider ha un limite (spesso da 20 a 50). Superarlo causa errori.

## Prova connessione

Premi **Prova connessione** prima di postare. Il test si collega, fa il login e ti dice se l'host, la porta, l'impostazione SSL o le credenziali sono sbagliati.

## Errori comuni

- *Impossibile connettersi*: host o porta sbagliati, internet assente, oppure un firewall o una VPN blocca la connessione.
- *Autenticazione non riuscita*: nome utente o password sbagliati. Riprova poche volte: i provider possono bloccare temporaneamente un account dopo molti login falliti.
- *Troppe connessioni*: riduci il numero di connessioni.

Vedi anche [Problemi comuni](12-problems.md).
