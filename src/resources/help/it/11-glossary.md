# Glossario

**Articolo**: un piccolo pezzo di un file postato su Usenet. Un post è fatto di migliaia di articoli.

**Newsgroup**: un forum di Usenet in cui vengono postati gli articoli, per esempio `alt.binaries.test`.

**NZB**: un file con l'elenco degli articoli di un post. Serve per scaricarlo.

**par2**: file di recupero. Permettono a chi scarica di riparare un post quando mancano alcuni articoli.

**Ridondanza**: la percentuale di dati par2 in più. Più alta significa più sicurezza ma più dimensioni.

**Offuscamento**: nascondere i nomi negli oggetti degli articoli. Solo chi ha l'NZB può trovare il post.

**RAR, 7z**: formati di archivio usati per impacchettare i file, con una password facoltativa.

**Connessione**: un collegamento con il server. Più connessioni caricano più in fretta, fino al limite del provider.

**SSL**: cifratura della connessione con il server.

**ETA**: tempo stimato rimanente.

**Coda**: l'elenco dei post in attesa di essere caricati.

**Provider**: l'azienda che ti dà accesso a un server Usenet.
