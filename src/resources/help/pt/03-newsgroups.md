# Newsgroups

Os newsgroups são os locais da Usenet onde os seus artigos são publicados. Definem-se em **Definições**, categoria **Publicações**, cartão **Newsgroups**.

## A caixa dos grupos

Cada newsgroup é uma pequena «etiqueta»:

- Escreva um nome e carregue em **Enter**, **Tab**, vírgula ou espaço para o adicionar.
- Enquanto escreve, é sugerida uma lista curta de grupos comuns.
- Clique no **×** de uma etiqueta, ou carregue em **Backspace** na caixa vazia, para a remover.
- Um nome que não é válido (por exemplo, sem um ponto) aparece a vermelho.

Um nome válido tem letras minúsculas, algarismos, `+`, `_` ou `-`, separados por pontos, por exemplo `alt.binaries.test`.

## Verificações antes de publicar

O ngPost não inicia uma publicação se não houver nenhum newsgroup, ou se algum deles não for válido. A mensagem pede-lhe que os corrija nas Definições.

## Para onde vão as publicações

Quando tem vários grupos, o menu ao lado da caixa escolhe para onde vai cada artigo:

- **Todos os grupos em cada publicação** (predefinido): cada artigo é publicado em todos os grupos.
- **Um grupo aleatório para cada publicação**: cada publicação vai para um grupo da lista, escolhido ao acaso.
- **Um grupo aleatório para cada ficheiro**: cada ficheiro vai para um grupo escolhido ao acaso. Isto precisa da opção de **ofuscação dos artigos** (em Privacidade).

Use um grupo de teste como `alt.binaries.test` enquanto aprende. Nas publicações a sério, use os grupos que o seu fornecedor e a comunidade esperam.
