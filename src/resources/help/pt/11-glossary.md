# Glossário

**Artigo**: um pequeno pedaço de um ficheiro publicado na Usenet. Uma publicação é feita de milhares de artigos.

**Newsgroup**: um fórum da Usenet onde os artigos são publicados, por exemplo `alt.binaries.test`.

**NZB**: um ficheiro com a lista dos artigos de uma publicação. É necessário para a descarregar.

**par2**: ficheiros de recuperação. Permitem a quem descarrega reparar uma publicação quando faltam alguns artigos.

**Redundância**: a percentagem de dados par2 extra. Mais alta significa mais segurança, mas mais tamanho.

**Ofuscação**: esconder os nomes nos assuntos dos artigos. Só quem tem o NZB consegue encontrar a publicação.

**RAR, 7z**: formatos de arquivo usados para empacotar os ficheiros, com uma palavra-passe opcional.

**Ligação**: uma ligação ao servidor. Mais ligações enviam mais depressa, até ao limite do seu fornecedor.

**SSL**: cifragem da ligação com o servidor.

**ETA**: tempo restante estimado.

**Fila**: a lista de publicações à espera de serem enviadas.

**Fornecedor**: a empresa que lhe dá acesso a um servidor Usenet.
