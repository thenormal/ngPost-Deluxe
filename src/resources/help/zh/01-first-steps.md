# 快速入门

本页带您从全新安装一直做到第一次发布。

## 您需要准备

- 一个 **Usenet 服务商**的账户（主机名、端口、用户名和密码）。
- 您想发布的文件或文件夹。
- 可选：用于压缩的程序（**7-Zip** 或 **RAR**）和用于生成 par2 文件的程序（**ParPar** 或 **par2**）。Windows 安装程序已包含 7-Zip 和 ParPar。

## 您的第一次发布

在设置好服务器和新闻组之前，快速发布和自动发布页面顶部会显示一条蓝色提示栏，告诉您还缺什么，并提供一个按钮直接打开对应页面。设置完成后它会自动消失。

1. 打开**服务器**，添加您的服务商，然后点击**测试连接**。参见[服务器与连接](02-servers.md)。
2. 打开**设置**，类别**发布**，卡片**新闻组**，至少添加一个新闻组。参见[新闻组](03-newsgroups.md)。
3. 打开**快速发布**，点击**选择文件**（或把文件和文件夹拖入窗口）。
4. 选择需要的选项（压缩、par2、密码），然后点击**发布文件**。
5. 在窗口底部和日志中查看进度。完成后，**NZB 文件**会被保存，并显示在日志中。

NZB 文件是您这次发布的“地图”：没有它，任何人都找不到这些文章，尤其是在使用混淆时。请妥善保管。

## 各功能在哪里

- **引导发布**: 回答几个问题, 发布就会为您准备好. 见[引导发布](01b-guided-post.md).
- **快速发布**：立即发布文件和文件夹。
- **自动发布**：扫描或监视文件夹。
- **服务器**：您的 Usenet 服务商。
- **设置**：程序的默认选项，分为五个类别（常规、发布、NZB 文件、通知、历史与队列）。
- **历史记录**：您发布过的所有内容。
- **帮助**：就是本部分。

## 新版本

程序每天启动时会向 GitHub 询问一次是否有更新的版本（GitHub 只能看到您的 IP 地址）。如果有，左侧栏底部会出现 **Version X available** 按钮：点击即可打开该版本的页面。程序不会自动下载或安装任何内容，候选版本（release candidate）也永远不会被提示。

如需关闭，请在**设置**的类别**常规**、卡片**界面**中取消勾选**程序启动时检查新版本**。命令行版本和 Docker 镜像从不检查。
