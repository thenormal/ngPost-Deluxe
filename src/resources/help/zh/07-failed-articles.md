# 失败的文章与重发

上传过程中，有些文章可能会失败（连接中断、服务器拒绝）。ngPost 会对每篇文章重试多次。如果仍有文章失败，这次发布会以橙色结束，日志会说明有多少篇文章失败。

## 重发缺失的文章

如果有文章发布失败，请在 **发布列表** 页面中选择该发布：**重新发布缺失的文章** 按钮会**只重新发布这些文章**并修复 NZB 文件，无需重新发送整个发布。

重新发布会作为新的一行出现在列表中；如果没有错误地完成，就不再缺少任何内容。

## 提示

- 如果大量文章失败，原因通常是连接。请减少连接数，或检查服务商的限制。
- 如果同样的文章一再失败，请检查您的账户和新闻组。
- 重试次数可以通过选项 `--retry`（默认为 5）或在配置文件中设置。

参见[服务器与连接](02-servers.md)。
