# 自动发布

自动发布可以一次发布大量文件和文件夹，而无需逐个手动准备。请选择页面顶部三个按钮之一；只会显示您需要的设置。

## 发布我选择的内容

添加您想要的文件和文件夹（拖入列表，或使用**选择文件** / **选择一个文件夹**），然后点击**发布列表**：每个文件或文件夹都会成为一次单独的发布。勾选 **暂停加入** 时（**扫描一次文件夹** 也适用），发布会在 **发布列表** 页面中等待，直到你恢复它们。

## 扫描一次文件夹

选择一个文件夹并点击**扫描**：其中的内容会被列出。文件夹需要**压缩**。使用**新文件在前**可以按日期排序。

## 监视文件夹并发布新到的内容

选择文件夹并点击**开始监视**：每个新文件或文件夹在到达时就会被发布。点击**停止监视**即可停止。如果仍有发布在等待时停止，会要求确认。

监视期间，三个选项下方的一栏会始终显示被监视的文件夹、今天已完成多少次发布（以及其中多少次出现错误），以及有多少次正在进行或等待中。**暂停监视**会让新文件等待：当您点击**继续监视**时才会发布；已经开始的发布会继续。停止监视会丢弃正在等待的文件。

## 列表

每个项目都有一个复选框和它的大小。取消勾选某个项目即可排除它；只有勾选的项目才会被发布。要从列表中移除项目，请选中它们并按 DEL。列表下方的一行显示已选中多少个项目、它们的大小、需要上传的大小，以及（第一次发布之后）上传所需时间。

## 已经发布过的项目

如果某些勾选的项目已经在历史记录中（名称和大小相同），会有一个窗口列出它们以及上次发布的日期。对于您想再发布一次的项目，请勾选**再次发布**；其他项目不会被发布，并保留在列表中，处于未勾选的灰色状态。如果已存在同名的 NZB 文件，新文件会命名为 `名称_1.nzb`，依此类推。监视文件夹时，已在历史记录中的项目会被跳过，并在日志中留下一行记录。您可以在**设置**（历史）中关闭这项提醒。

## 开始之前

当您点击**发布列表**或**开始监视**时，程序会对整个分组一次性检查设置（服务器和新闻组、文件夹的压缩、rar / 7z 和 par2 程序、NZB 文件夹、临时文件夹）。问题会用通俗的话显示，并附带一个修复按钮；警告可以通过**仍然发布**忽略。它与[快速发布](04-quick-post.md)中的窗口相同。

## 名称、新闻组和服务器

**名称、新闻组和服务器**卡片与[快速发布](04-quick-post.md)中的这些行相同，并多了一行：**NZB 文件夹**，即这些发布的 NZB 文件写入的位置（留空：使用设置中的文件夹）。它同样适用于被监视的文件夹。配置可以保存这些设置。

## 提示

- 使用压缩、随机名称、随机密码和 par2：这是自动发布的常用设置。**推荐**配置（菜单**配置**）可以一键设置好。
- **发布后**（发布按钮上方的一行）：什么都不做（默认）、把文件移动到 **“Posted” 文件夹**，或删除它们。默认名称 `Posted` 会在每个文件或文件夹旁边创建该文件夹；您也可以选择其他文件夹。只有发布无错误完成后，才会移动或删除任何内容。文件夹中已存在的名称绝不会被覆盖：文件会变成 `名称 (2)`。扫描和文件夹监视会忽略 “Posted” 文件夹。删除是永久的：只有在确定时才使用。
- 在命令行中，同样的选择是 `--move_posted` 或 `--rm_posted`（参见[命令行](10-command-line.md)）。
- 程序会记住您上次使用的按钮。
- 对于 NAS 或没有屏幕的服务器，命令行和 Docker 镜像可以完成同样的工作。

参见[命令行](10-command-line.md)。
