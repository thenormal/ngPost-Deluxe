# NZB 文件

NZB 文件列出了一次发布中的所有文章。任何拿到它的人都可以从 Usenet 下载这次发布。

## 保存位置

文件夹在**设置**的类别 **NZB 文件**中设置。文件使用发布的名称（第一个文件或文件夹的名称）。

## 使用方法

- 与压缩包密码一起分享（如果您设置了密码）。
- 下载程序（新闻阅读器）会打开它并下载文件。
- 使用混淆时，NZB 是找到您的发布的**唯一**途径：请保留一份副本。

## 检查 NZB

在命令行中，`--check` 会验证某个 NZB 中的文章在服务器上是否仍然可用。

## 历史记录

**历史记录**页面列出您过去的上传（日期、名称、大小、速度、压缩包、密码、新闻组）。您可以在设置中关闭历史记录。密码以明文保存。

### 已在历史记录中的发布

发布开始之前，ngPost 会在历史记录中查找 NZB 名称相同且文件总大小相同的成功发布。在**快速发布**中，会弹出窗口询问是否再次发布（**仍然发布**或**取消**）。在**自动发布**和命令行中，该发布会被跳过，日志中会有一行说明。若仍要再次发布，请使用选项 `--allow_repost`，或在**设置**的类别**历史与队列**（上传历史卡片）中关闭这项提醒。该检查要求历史记录处于开启状态，并且只比较名称和大小：重命名过的文件夹无法被识别。

## NFO 文件

NFO 是一个描述这次发布的小文本文件：名称、日期、文件及其大小、准备方式（压缩包和 par2）以及您自己的一段文字。请在快速发布或自动发布的 **NFO 文件**卡片中启用（它们是同一张卡片：设置是共享的）。

- **在 nzb 旁边写入 NFO 文件**：`名称.nfo` 保存在与 `名称.nzb` 相同的文件夹中。
- **同时把 NFO 文件与文件一起发布**：它会随这次发布一起上传，并出现在 NZB 中。
- **包含媒体信息（MediaInfo）**：默认开启。对于视频和音频文件，NFO 会列出时长、视频（格式、尺寸、帧率、HDR）、音轨（语言、格式、声道、码率）和字幕。最多描述 20 个文件（其余只计数），读取在 20 秒后停止。它使用免费程序 MediaInfo：Windows 安装程序和 Docker 镜像已包含它；在 Linux 和 macOS 上请安装 `mediainfo` 软件包，或在设置中选择该程序。没有 MediaInfo 时，NFO 只是没有媒体部分。
- **写入压缩包密码**：默认关闭。在已发布的 NFO 中，任何下载这次发布的人都可以读到密码。
- **末尾附加的文字**：备注、链接，任何您想说的话。所有发布使用同一段文字。

当文件名被隐藏时（文章混淆或文件名混淆），已发布的 NFO 不会列出任何文件名或媒体信息，并且该文件本身会使用随机名称。在命令行中请使用 `--gen_nfo`、`--nfo_in_post`、`--nfo_password` 和 `--nfo_text file.txt`，以及 `--no_nfo_media` 和 `--mediainfo_path 路径`。
