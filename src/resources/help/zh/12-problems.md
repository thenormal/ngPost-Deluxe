# 常见问题

## 登录被拒绝

请检查用户名和密码、主机和端口，以及 SSL 设置。使用**测试连接**。不要连续多次重试：多次登录错误后，服务商可能会把账户封锁一段时间。

## 上传很慢

请增加连接数，最多到服务商的上限。检查 SSL 是否拖慢了老旧电脑，以及是否有其他程序在占用您的线路。

## “没有新闻组”或“新闻组无效”

打开**设置**，类别**发布**，卡片**新闻组**，添加有效的名称。参见[新闻组](03-newsgroups.md)。

## NZB 文件已存在

请选择其他名称或文件夹，或在程序询问时同意覆盖。

## 临时文件夹已存在

之前的一次发布被突然中断了。请删除那次发布遗留的临时文件夹，然后重试。

## 有些文章失败了

使用**重发缺失文章**。参见[失败的文章与重发](07-failed-articles.md)。

## 我需要帮助

保存**诊断报告**（快速发布中日志下方的按钮），并在 GitHub 的项目页面上描述问题。
